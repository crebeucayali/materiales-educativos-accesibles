Pictogramas y apoyos visuales

Busca pictogramas por palabra clave

Esperando búsqueda

Escribe una palabra en español. La página consultará la base de datos de ARASAAC y mostrará los pictogramas relacionados.

Resultados de pictogramas

Realiza una búsqueda

Puedes iniciar con palabras como "comer", "baño", "ayuda", "escuela" o "esperar".

No se pudo completar la búsqueda

Revisa tu conexión o intenta con otra palabra. Si el problema continúa, puede deberse a una interrupción temporal del servicio externo.

Uso educativo

Apoyo visual para comunicación y comprensión

Los pictogramas pueden utilizarse para anticipar actividades, organizar rutinas, apoyar instrucciones, elaborar tableros visuales y favorecer la accesibilidad cognitiva en contextos educativos y familiares.

i

Advertencia pedagógica

Este recurso es un apoyo visual. La selección de pictogramas debe considerar la edad, el contexto, el nivel de comprensión y las necesidades comunicativas de cada estudiante.
